# WebCraftPro AI — Real Estate Automation Platform

Investor demo of an AI-powered lead qualification and business automation platform focused on real-estate companies.

## Screens

- **Overview** — Landing with branding and CTA to test the AI agent
- **Command Center** — Dashboard with DEMO DATA metrics and recent leads table
- **Live AI Agent** — Interactive qualification chat (buy/rent, property type, budget, location, timeline)
- **Lead CRM** — Qualified leads list with detail panel
- **Automation Flow** — Visual pipeline from Lead → Sales Follow-up
- **Investor View** — Problem, solution, customers, model, GTM, foundation, vision

## Tech

- Next.js (App Router)
- TypeScript
- Tailwind CSS

No API keys required. Demo runs fully client-side for the agent flow.

## Local

```bash
npm install
npm run dev
```

## Deploy

Connected to Vercel via GitHub.
